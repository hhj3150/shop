## 2. 평소 운영 규칙

1. **손님이 읽는 내용(본문·가격·정책·구조화데이터)을 바꾸면** `lib/seo/lastmod.ts` 의 그 페이지 날짜를 **배포되는 날**로 고친다.
   → 다음 날 06:20 KST 에 IndexNow 예약 함수가 lastmod 가 '어제'인 주소만 Bing·네이버에 한 번 알린다(중복 없음).
   → PR 이 늦게 머지돼 lastmod 보다 늦게 배포됐다면, 배포 후 `node scripts/indexnow.mjs --since <그 날짜>` 를 한 번 돌린다.
   → 관리자 화면에서 DB 가격을 바꿨을 때도 해당 제품 날짜를 올린다(검색 문구는 1시간 안에 DB 가격으로 바뀐다).
2. **새 공개 페이지·제품**을 만들면: `lastmod.ts` 에 날짜, `lib/seo/sitemap.ts` 의 `SITEMAP_PAGES`(페이지), 메타데이터는 `pageMetadata` 로.
   제품 누끼 PNG 는 `public/products/<id>.png` 규칙(공유 카드가 읽는다).
3. **제목은 자주 바꾸지 않는다**(네이버 불이익). 제목 안에서 같은 낱말을 되풀이하지 않는다(테스트가 잡는다).
4. 검색·AI 문구에 쓰지 않는 말: `건초만`·`풀만`(사실과 다름), `방목`, `일반 우유`·`~보다`(비교), 소화·건강 효능, 근거 없는 `최초/최고/유일`.
   인증은 **농장 인증**으로만(‘동물복지 우유’ ✕ → ‘동물복지축산농장 인증 목장’ ○).
5. **하지 않는 것**(구글 스팸 정책): AI 봇에게만 다른 화면 보여 주기(클로킹), 숨김 글자, 가짜 후기·별점, 키워드 반복용 대량 페이지.

## 7. 헤이밀크 표기 — ARGE Heumilch(heumilch.com)·EU 사양 참고 (2026-11-13)

heumilch.com(오스트리아 헤이밀크 단체 ARGE Heumilch)과 EU 사양 원문(위원회 시행규정 (EU) 2016/304, 규정 (EU) 2024/1143)을
4갈래로 읽고, 새로 넣은 문장마다 출처 원문을 다시 대조했다(반박 검증 28건 중 22건 통과, 6건은 고친 문장으로 반영).
재발 방지 테스트: `lib/seo/haymilk-claims.test.ts`.

**원칙** — '헤이밀크'는 우리가 따르는 **사육 방식**의 이름으로만 쓴다. EU TSG 인증 제품이 아니고, EU 사양 세부 준수도 검증받지 않았다.
- 'TSG'를 말하는 곳에는 반드시 '인증 제품은 아니다'를 함께 쓴다(홈·/story·FAQ·llms·도우미·/learn).
- 제도 이름은 '전통특산물보증(TSG)'. EU 가 등록한 것은 **이름**(Heumilch/Haymilk)이다.
- '그 방식 그대로'처럼 사양 전부를 지킨다고 읽히는 말을 쓰지 않는다.
- ARGE·EU 자료의 **영양·효능·맛·비교 주장은 옮기지 않는다**(오메가-3·CLA '약 2배', 장 건강, '가장 자연스러운', 클로스트리디아 비교, '유럽 우유의 3% 미만' 희소성 등).
- ARGE 초록 로고·EU TSG 표장을 배지·마크 형태로 쓰지 않는다. '헤이밀크 요거트'처럼 이름처럼 붙이지 않는다(EU 인증 생산자도 'aus Heumilch'로 표기).

**바꾼 것** — /learn/hay-milk(EU 사양 명칭 정정, GM 금지 범위, 사일리지·곤포 금지를 EU 사양 규칙으로, 검사 제도·ARGE 소개 소제목, EUR-Lex 원문 출처),
FAQ 헤이밀크·저지 답변, llms 안내, /story Provenance, 홈 WhyBand 안내 한 줄(+ 해설 링크), 도우미 지식(방식→맛 인과 삭제), 제품 문구('그대로'·'더' 삭제), 카피 가이드 예문.

**사장님 확인 결과 (2026-11-13)**
1. 사일리지·헤일리지 등 발효 조사료는 쓰지 않는다. 조사료는 건초뿐이고 생풀은 먹이지 않으며, 곡물·미네랄 등 보조사료는 먹인다 → 사이트 전체의 사료 표현을 **'사일리지(발효사료) 없이 건초를 중심으로'** 로 통일했다('풀과 건초'는 EU 헤이밀크 방식을 설명할 때만). 카피 가이드에 반영.
2. ARGE Heumilch 회원이 아니고 국내에는 헤이밀크 인증 제도가 없다 → /learn/hay-milk 마지막 소제목에 명시.
3. 해설은 사료 수치 없이 쓴다('그 대부분') — 카피 가이드의 사료 수치 금지 유지.
4. 내수 전용 판매 → EU 표기(2024/1143) 법률 검토는 보류. 수출·EU 대상 광고 계획이 생기면 다시 본다.
5. 요거트 당류 비교(원유 5.9g → 3.5g)는 근거 자료가 없어 삭제를 확정한다. 지방산 분석 성적서(26-06-BR0114·BR0115)는 있어 그 표기는 유지.

## 8. A2 우유·저지 해설 보강 (2026-11-13)

헤이밀크 글과 같은 방식으로 원문(UniProt·논문·AJCA·RJA&HS·Jersey Canada·World Jersey·농촌진흥청·농식품부·한국종축개량협회)을 4갈래로 읽고
