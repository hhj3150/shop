# 현금영수증 자동발행 전환 — 관리자 운영 안내

**적용일: 2026-08-30** · 대상: 관리자 화면을 쓰는 모든 담당자

---

## 한 줄 요약

**오늘부터 페이액션 대시보드에서 현금영수증을 손으로 발행하지 마세요.**
입금이 확인되는 순간 자동으로 발행됩니다. 손으로 또 누르면 **이중발행**입니다.

---

## 무엇이 바뀌었나

| | 전 | 후 |
|---|---|---|
| 발행 주체 | 관리자가 페이액션에 로그인해 '현금영수증 → 발행하기' | 입금 매칭 시 페이액션이 **자동 발행** |
| 금액 입력 | 관리자가 우리 화면의 면세·공급가액·부가세를 보고 손으로 입력 | 주문할 때 계산된 값이 자동으로 넘어감 |
| 발행 여부 확인 | 우리 화면에 기록이 없어 알 수 없었음 | 주문 상세에 **자동발행 완료 + 영수증 ID** 표시 |

## 화면에서 이렇게 보입니다

주문 목록의 '현금영수증' 칸:

| 표시 | 뜻 | 할 일 |
|---|---|---|
| **자동발행** | 페이액션이 발행 완료 | **아무것도 하지 마세요** |
| **발행대기** | 아직 입금 전 | 기다립니다 |
| **자동발행 실패** | 발행이 실패함 | 아래 '실패했을 때' 참고 |
| **발행취소** | 주문취소와 함께 영수증도 취소됨 | 아무것도 하지 마세요 |
| **발행완료** | 예전에 손으로 발행하고 표시해 둔 건 | 그대로 둡니다 |

주문 상세를 열면 금액 아래에 안내가 뜹니다.

- 자동발행된 건: *"페이액션이 입금 확인과 동시에 자동 발행했습니다 (영수증 ID 12345). 대시보드에서 다시 발행하지 마세요 — 이중발행됩니다."*
- 아직인 건: *"입금이 확인되면 페이액션이 자동 발행합니다. 손으로 발행하지 마세요."*

## 실패했을 때만 사람이 나섭니다

'자동발행 실패'로 뜨고 실패 사유가 함께 표시됩니다(예: 식별번호 오류).
그 자리에 **[현금영수증 재발행]** 버튼이 생깁니다 — 누르면 같은 금액으로 다시 시도하고,
성공하면 화면이 바로 '자동발행 완료'로 바뀝니다. **페이액션에 들어갈 필요가 없습니다.**

재발행이 계속 실패하면(식별번호 자체가 틀린 경우 등) 손님께 번호를 확인한 뒤,
페이액션에서 직접 발행하고 우리 화면에서 '발행완료'로 표시해 주세요.

이미 발행된 주문에는 재발행 버튼이 나오지 않습니다(서버가 한 번 더 막습니다).

## 손님이 '발행 안 함'을 고른 주문 — 확인 필요

거래구분·식별번호를 보내지 않습니다. 페이액션 문서에 따르면 **자진발급 설정이 켜져 있고
거래구분·식별번호가 둘 다 없는 주문은 국세청 지정번호(010-000-1234)로 자동 자진발급**됩니다.
최근 90일 기준 이런 주문이 **44건**입니다.

사업자 의무발행 대응이라 그 자체로 문제는 아닙니다. 원치 않으시면
대시보드 > 기능설정 > 현금영수증 [환경설정 수정]에서 자진발급을 끄시면 됩니다.

## 왜 '둘 다' 보내거나 '둘 다' 안 보내는가

문서 규정입니다 — 거래구분과 식별번호 **둘 중 하나만** 전달되면 자동발행도 자진발급도
되지 않습니다. 그래서 우리 시스템은 둘을 쌍으로만 보냅니다.

손님이 '소득공제'를 골랐는데 휴대폰 번호가 비어 있으면 그 주문은 자진발급으로 넘어가
**손님이 연말정산 공제를 못 받습니다.** 주문 폼이 번호를 필수로 받고 있어 지금은 0건이지만,
혹시 생기면 서버 로그에 경고가 남습니다.

## 금액은 어떻게 정해지나

우리 시스템이 계산해서 보냅니다. 규칙은 종전과 같습니다.

- 우유 = **면세**, 요거트 = **과세** (판매가는 모두 부가세 포함가)
- 배송비: 과세 품목이 하나도 없으면 면세, 그 외에는 과세
- 정기구독은 **회당 수량 × 주수**로 계산 (이걸 빼먹으면 면세가 모자라고 부가세가 부풀려짐)
- 적립금 등으로 깎였으면 면세·과세에 비례 배분 — **면세 + 공급가액 + 부가세 = 실결제액**이 항상 맞습니다

## 취소·환불할 때

주문을 취소하면 페이액션에도 취소가 전달되고, **연결된 현금영수증도 함께 취소됩니다.**
그 결과가 우리 화면에 '발행취소'로 표시되므로, 따로 현금영수증만 취소할 필요는 없습니다.

**드물게 영수증 취소만 실패할 수 있습니다.** 그때는 주문은 취소됐는데 영수증은 살아 있는
상태라 화면에 실패 사유가 표시됩니다. 이 경우에만 페이액션에서 해당 영수증을 직접 취소해 주세요.

## 이상하면 이렇게 확인합니다

주 1회 `supabase/audit-notify-consistency.sql`을 돌리면 아래 두 항목이 함께 나옵니다.

- **현금영수증 신청했는데 미발행** — 입금은 됐는데 영수증이 안 나간 건
- **이중발행 의심** — 자동발행과 수기 표시가 겹친 건

둘 다 0이어야 정상입니다.

## 궁금한 점

- 자동발행이 되는지 눈으로 확인하고 싶다면: 입금이 매칭된 주문을 열어 '자동발행 완료'와
  영수증 ID가 뜨는지 보면 됩니다.
- 예전에 손으로 발행한 건들은 그대로 둡니다. 새로 들어오는 주문부터 자동입니다.
