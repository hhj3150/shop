## 3. 이번 변경 (홈 재구성 · 구매 방식 구분)

홈 순서: **인사(짧게) → 상품 → 사는 방법 → 정기구독 안내 → 이름 풀이·인증 → 목장 집사 → FAQ → 매장**

- **히어로**: 모바일에서 제품 정렬컷·버튼을 빼고 인사만 남겨, 첫 화면에 상품 카드가 들어온다
  (360px·390px 모두 첫 상품 사진 전체가 탭바 위에 보임).
- **상품 카드**: 대표 가격을 회원가 → **정가**로. 아래에 `정기구독 ₩9,600~ · 10~20% 할인`.
  버튼은 `구독 신청` → `구매하기`.
- **사는 방법(HowToBuy)**: 1회 구매(회원가입 없이·정가·최소 24,000원·배송비 4,000원)와
  정기구독(창립 500인·10~20% 할인·4·8·12·24주 선납)을 나란히. 숫자는 전부 `lib/products`.
- **이름 풀이·인증(WhyBand)**: 기존 문구만 모아 한 밴드로. 새로 지은 문장 없음.
- **/story(신설)**: 희소성·재생농업·목장 소식·세계 낙농 소식을 **지우지 않고 옮김**.
- **FAQ**: 접이식(`<details>`) — 답은 HTML 에 그대로 있어 구조화 데이터와 일치.
- **상세**: `?mode=once` 로 1회 구매 탭 열기, 고른 조건을 한 문장으로 되읽는 요약.
- **문구 정정**: 가입 화면 "우유는 회원께만" → "정기구독은 회원께만" + 1회 구매 링크.
  매장 안내 "온라인은 회원께만 엽니다" → "온라인 정기구독은 회원께만 엽니다".

정책·가격·주문 로직·운영 DB 는 건드리지 않았다.

### 3-1. 후속 (상세의 구매 방식 구분)

- **구매 방식 탭**에 한 줄 설명: `정기구독 · 매주 · 10~20% 할인` / `1회 구매 · 정가 · 가입 없이`.
- **상단 가격이 탭을 따라간다**: 정기구독 탭에서는 회원가(정가 취소선), 1회 구매 탭에서는 정가.
- 상단 가격의 단위 `/ 회` → `/ 병`. 병 하나의 값인데 '회당'으로 적혀, 2병이 기본인 패널의
  회당 금액과 어긋났다.
- **기간 버튼에 병당 가격**을 함께 표시(할인율만으로는 손님이 직접 계산해야 했다).
- 목장 집사 예시 질문의 "왜 소화에 편한지" → "일반 우유와 무엇이 다른지"(효능 단정 표현 제거).
- 360×740 에서 첫 상품 사진이 탭바에 17px 가리던 문제 수정(#222).

## 4. 검증

- `tsc` 0 · `vitest` 1,323건 통과 · `next build` 성공
- 정기구독 금액: 화면 병당가 = 서버 산식(정가 4종 × 기간 4종, 운영 DB 값 대조),
  기간별 합계(4·8·12·24주), 출발 수량, 한 줄 요약의 합계 갱신(24주 3병 = 787,200원)
- Playwright 360·390·768·1440px: 홈 첫 화면 상품 노출, 카드 가격, 사는 방법, 홈→1회 구매,
  `?mode=once`, 요약 갱신, /story, 가로 넘침 없음
- 이전 단계 구매 흐름(상세·결제·1회 구매·마이페이지) 재실행
- axe-core: 홈·/story 위반 0

로컬 프로덕션 빌드 + 더미 Supabase 주소 + 가짜 로그인 세션으로 검증했다.
**운영 DB 쓰기, 실제 주문·결제는 하지 않았다.**

## 5. 근거 확인이 필요한 표현 (이번에 바꾸지 않음)

화면에 이미 있는 표현 중, 라벨·품목제조보고·시험성적서·통계와 대조가 필요한 것.
문구를 임의로 고치지 않았다 — 근거가 확인되면 유지, 아니면 수정한다.

| 표현 | 위치 | 필요한 근거 |
|---|---|---|
| "대한민국 0.01%의 희소한 A2/A2 저지소" · "국내 0.01%" · "0.01%의 소로, 0.01%를 위해" | 사이트 설명(meta), 제품 설명, 상세 선언문 | 산출 근거(분모·분자·기준 시점) |
| "100% A2 저지 착유목장 단 한 곳" · "A2 저지 단 한 곳" | /story, 상세 신뢰 배지 | '유일'의 범위와 출처 |
| "국내 젖소 38만 두 · 저지 1,000여 두" | /story | 통계 출처·기준 연도 |
| 유산균 수 **"1g당 7.2억 CFU"** vs **"1 mL당 7.2억 CFU"** vs "7.2억 CFU/mL" | 상세 시그니처 캡션 / 제품표시 / 카드 스티커 | 시험성적서의 단위(g 인지 mL 인지) — **화면 안에서 단위가 서로 다르다** |
| "총 1,296억 CFU"(180mL) · "총 3,600억 CFU"(500mL) | 제품표시 | 위 단위 확정 뒤 재계산 |
| "유산균(덴마크) 0.003%" · "덴마크 프리미엄 유산균" | 제품표시, 도우미 지식 | 원료 규격서 |
| "HTST 살균 (75℃, 20초)" | 제품표시 | 품목제조보고 |
| "오메가 6:3 = 2:1" · "공인 영양성분 분석 26-06-BR0114" | 상세 시그니처 | 성적서 원본·시료 범위 |
| "소화 과정에서 펩타이드 BCM-7을 만들지 않습니다" | /story | 표시광고 검토(건강 관련 표현) |
| "A2 저지 우유가 왜 소화에 편한지" | 목장 집사 예시 질문 | 표시광고 검토 |
| "장–뇌 축 … 소화·면역·기분에 영향" | /story | 표시광고 검토 |
| "유럽이 전통특산물(TSG)로 지키는 헤이밀크의 방식" | /story | 국내에 해당 인증이 있는 것처럼 읽히지 않는지 |
| "저탄소 인증 1호" · "동물복지 인증 1호" | (제거됨) | 근거가 있으면 범위를 밝혀 복원 |
| 깨끗한 축산농장 지정 | (만료로 미표시) | 재지정서 |
| 경기도 가축행복농장 인증 | 인증 목록 | 현재 유효 여부(인증서에 기간 없음) |

## 6. 미해결·다음 단계
